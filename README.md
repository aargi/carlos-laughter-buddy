# Laughter Lab

Quiero crear una aplicación de risoterapia donde una IA llamada Carlos sea el facilitador virtual de la sesión.

El flujo de la sesión es mecánico y estructurado:
1. Carlos explica cada ejercicio.
2. Carlos hace la demostración (con voz, sonidos de risa y animación reactiva).
3. Turno del usuario para repetir con temporizador visual y botón de "Siguiente ejercicio" para avanzar.

La sesión debe tener progresión de intensidad:
- El Nivel 1 (Suave) debe estar compuesto por 3 ejercicios básicos de calentamiento vocal antes de los más complejos: primero "ja, ja, ja", después "je, je, je", y "ji, ji, ji", cada vez con un poco más de ritmo e intensidad.
- Luego ejercicios dinámicos de mayor intensidad (como el teléfono risueño, la risa del león y carcajada libre final).
- Pantalla de inicio para comenzar la sesión y pantalla de cierre con respiración de vuelta a la calma y registro de estado de ánimo.
